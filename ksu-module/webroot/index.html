自动亮度上限

仅截断系统自动亮度输出，手动亮度不受影响。百分比使用 AOSP 亮度滑块的 Gamma 映射近似换算。

AOD 亮度比例

以系统记录的正常屏幕亮度为基准，乘以此比例。100% 为相同归一化亮度目标；最终仍可能受 AOD 遮罩、低亮度保护和驱动限制。

比例10%
1%100%

OLED AOD 长时间高亮可能增加功耗和烧屏风险。建议先使用 5–15%，不要直接设 100%。

若滑块调整后没有立即变化，开关屏幕或等待下一次自动亮度更新。首次启用前，请先在 LSPosed 中启用 APK，并勾选 System Framework（system / android）与 System UI。
